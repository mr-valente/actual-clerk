# Budget setup

Actual Clerk reports one headline number, **free money**: what is left each month once everything already promised is accounted for.

```
free money = expected income - committed spending
remaining  = free money - what you have spent since the 1st
```

Producing it takes a one-time setup in Actual: budget your recurring bills, and leave everyday categories unbudgeted. Clerk treats any non-income category carrying a budget as committed, and everything else as money you are free to spend.

Actual offers two budgeting methods. Both work. Pick one and follow its guide.

## Which method?

| | [Tracking Budget](tracking-budget.md) | [Envelope Budget](envelope-budget.md) |
| --- | --- | --- |
| What you budget | Expected income and expenses, in advance | Only money already in your accounts |
| Its headline number | **Projected Savings** — income minus commitments | **To Budget** — what is left to assign now |
| Month to month | Each month is its own forecast | Category balances roll forward |
| Upkeep | *Copy until year end* budgets a whole year at once | *Copy last month's budget*, each month |
| Income | Budgeted in Actual; Clerk reads it directly | Set once in Clerk's settings |
| Fit with this report | Free money **equals** Actual's Projected Savings | Free money is Clerk's own calculation |

**[Setting up a Tracking Budget](tracking-budget.md)** is the closer fit. Actual's Projected Savings is the same calculation Clerk performs, so the two apps show the same number, and a year of bills can be budgeted in one action.

**[Setting up an Envelope Budget](envelope-budget.md)** is Actual's default and its own recommendation. Choose it if you want every dollar assigned a job and are content leaving Actual's *To Budget* figure high, since this report needs everyday categories left unbudgeted.

Switching between them is reversible. Actual keeps each method's amounts in a separate table inside your budget file, so changing the setting converts nothing and deletes nothing.
